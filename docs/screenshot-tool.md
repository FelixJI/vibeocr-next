# 截图识别操作

默认全局快捷键为 `Ctrl+Alt+Q`，可在设置页修改。注册冲突时，设置页保留配置值，显示失败原因及实际生效的快捷键；解除占用后可点击“应用”重试。

## 框选与确认

- 拖动创建选区，松开左键后进入待确认状态，不立即发送 OCR。
- 在选区内部拖动可移动选区，在边缘或八个控制点附近拖动可调整尺寸。
- 按 `Enter` 或点击“识别”提交原始快照中的选区。
- 右键：拖动中恢复拖动前的状态；待确认时清空选区；空选区时退出。
- `Esc` 始终退出截图。退出或外部取消后恢复主窗口和原任务栏状态。
- 撤销与重做只影响当前截图会话中的选区操作，不撤销已经提交的 OCR 任务或识别结果编辑。

## 快捷键

| 按键 | 操作 |
| --- | --- |
| Enter | 确认识别 |
| Esc | 退出截图 |
| 方向键 | 移动选区 1 个物理像素 |
| Shift + 方向键 | 移动选区 10 个物理像素 |
| Ctrl + 方向键 | 调整选区右边缘／下边缘 1 个物理像素 |
| Ctrl + Shift + 方向键 | 调整选区右边缘／下边缘 10 个物理像素 |
| Ctrl + Z | 撤销 |
| Ctrl + Y / Ctrl + Shift + Z | 重做 |
| M | 显示／隐藏放大镜 |
| Ctrl + C | 复制当前取样像素的 HEX 色号 |

放大镜展示鼠标周围 11 × 11 个原始像素，中心红框对应色号；同时显示桌面坐标、HEX 和 RGB。取色来自冻结快照，不受遮罩及选框颜色影响。

该流程用于截图 OCR，不包含画笔标注、图片文件保存或截图图片复制。标注功能仍使用识别结果页面既有编辑器。
