# 截图与编辑能力对齐清单

核对日期：2026-10-15。目标是分阶段对齐 PixPin / ShareX 的截图、编辑、贴图与输出体验。P0 已完成本地实现与相关验证，尚未远端合并；P1–P6 为范围基线，实施状态与依赖以文末 AI Flow Issues 为准。本轮仅创建规划，不启动远期实现。

## 已确认的交互原则

- 上排是全部工具和操作入口；下排只显示当前工具或选中对象的属性。
- 宽度不足时横向滚动，不压缩图标、不把操作混入属性排。
- 表格、公式、马赛克等工具不能因“简洁”而消失；没有运行能力时说明原因，不伪装成成功。
- 图标以真实使用语义为准。用户已否决“应用四格/水滴”和“九宫格/扩散圆点”，确认 IconPark 交错色块 Mosaic 与本项目真实虚化效果缩略图；全部 44 项已完成 Tabler / IconPark 对比。用户定稿 A：其余保留 Tabler，仅重新框选（selected-focus）和手形平移（hand-drag）改用 IconPark。
- 原生框选、现场编辑、独立编辑共用语义与资产；纯编辑不启动 OCR 或安装模型。
- 原图保留。预览、复制、保存、贴图、识别消费一致的最终像素；识别排除区继续遵守单独契约。

## 分阶段实施与验收

### P0：修正当前体验（本轮）

- [x] 马赛克/模糊的专用图形得到用户确认。
- [x] 其余图标通过完整对比定稿，并统一原生与 Web 入口：A，重新框选和平移采用 IconPark。
- [x] 矩形/椭圆分别设置边框颜色、不透明度、填充开关、填充颜色与不透明度。
- [x] 已绘对象可选中改样式，撤销/重做恢复像素效果；缺少新字段的历史对象保持原效果。
- [x] 单元验证 0%、100% 与旧标记默认值；真实预览及导出验证半透明填充，预览验证独立边框混色；荧光笔保持既有默认效果。

验收：选中红边矩形，设置蓝色 40% 填充和 70% 边框；复制/保存一致，撤销恢复；切到选择工具仍能编辑所选对象的属性。透明度控件用“不透明度”标签，0%=完全透明，100%=完全不透明。

### P1：完整的基本标注（依赖 P0）

- 普通形状八点缩放、箭头端点调整、Shift 正方形/正圆及 45° 约束；Alt 从中心绘制。
- 直线、折线；实线/虚线/点线；矩形圆角；空心/实心、单向/双向箭头。
- 文字双击编辑、多行、字体、字号、粗体/斜体/下划线、对齐、文字背景与描边。
- 序号起始值、数字/字母、形状、手动重编号；文字气泡/箭头说明。
- 每种工具记住自己的属性，并提供重置；滚轮调粗细与快捷键不抢输入框事件。

验收：标注在裁剪、缩放和整图旋转后仍可编辑；一段绘制/拖动形成一条历史；Esc 放弃草稿，不删除已完成对象。

参考：[PixPin 几何工具](https://pixpin.cn/docs/mark/geo)、[箭头](https://pixpin.cn/docs/mark/arrow)、[文字](https://pixpin.cn/docs/mark/text)。

### P2：对象操作与组合（依赖 P1）

- 多选/框选、全选、复制/粘贴/重复对象、方向键微移、删除。
- 置顶/置底/前移/后移；对齐、等距、组合/解组、锁定/解锁。
- 对象旋转、保持比例缩放、镜像；命中测试按实际形状与可见区域工作。
- 粘贴或拖入图片作为对象；文本粘贴为文字对象；由 C# 宿主授权文件和剪贴板访问。
- 工程保存/恢复保留原图、对象及样式；扁平图片导出与可编辑工程清楚区分。

验收：组合变换和撤销完整；复制对象不共享可变样式；导出顺序与画布一致；重开工程不丢文字、图片和修补效果。

### P3：遮挡、修补与视觉强调（可在 P1 后与 P2 分开推进）

- 马赛克/模糊支持矩形与自由笔刷、笔刷尺寸、连续强度；已画区域可重新调强度。
- 纯色不透明遮挡与 OCR 排除区分开；输出可明确验证原像素是否真正被覆盖。
- 智能擦除支持掩膜增减、原图对照、取消及质量提示；大图有明确资源边界。
- 重复内容匹配批量遮挡，提供候选预览、逐项增删；不把未确认候选直接当成完成结果。
- 聚光灯、多区域强调、画面内局部放大镜；标注橡皮擦、文字/图片水印。

验收：区域变换后不偏移；保存、复制与识别一致；撤销恢复被遮挡的编辑状态；重复目标误匹配可纠正。

参考：[PixPin 遮挡与修补](https://pixpin.cn/docs/mark/mosaic)、[聚光灯](https://pixpin.cn/docs/mark/highlight)、[放大镜](https://pixpin.cn/docs/mark/magnifier)。

### P4：截图、长截图与贴图（依赖稳定的编辑输出接口）

- 统一全屏、活动窗口、指定显示器、固定区域、上次区域、延时截图入口与快捷键。
- 捕获光标、阴影与窗口边框选项；窗口智能候选、跨屏与混合 DPI 的可预测行为。
- 长截图自动滚动、反向/横向、固定栏处理、拼接预览与手工纠偏；逐项明确支持边界。
- 贴图内编辑/裁剪/旋转、鼠标穿透、折叠、编组、同步移动、退出恢复。
- 贴图内容扩展到文字、颜色、公式、文件预览；与原图 OCR 绑定保持独立。
- 截图历史检索、重开编辑、容量限制、单项删除与清空入口。

验收：取消后宿主窗口状态恢复；多屏坐标准确；长截图失败不会输出伪完整结果；贴图编辑互不污染。

参考：[PixPin 贴图](https://pixpin.cn/docs/pin/base-use)、[ShareX 捕获概览](https://github.com/ShareX/ShareX#screenshot-and-screen-recording-features)。

### P5：排版、OCR 与输出工作流（依赖 P2/P4）

- 边距、背景色/渐变/图片、阴影、画布圆角、固定比例；多图横纵拼接与中段裁除。
- 输出预设、文件名模板、默认目录、格式/质量/尺寸、复制后关闭等行为可配置。
- 工具栏显示、排序和快捷键自定义；保留全部工具可发现性，下排继续仅放属性。
- 编辑后的文字/表格/公式识别入口统一；结果选字、校对、导出不使用旧图缓存。
- 批量图片沿用同一输出预设；如加入翻译，明确引擎、联网和原文/译文切换。

验收：预设能复用且不会覆盖原文件；不同格式的透明背景行为清楚；OCR 消费的是当前完成画面。

参考：[ShareX 编辑器](https://getsharex.com/docs/image-editor)、[ShareX 图像效果](https://getsharex.com/image-effects)。

### P6：录屏与产品级扩展（单独设计，最后推进）

- 视频/GIF 录制、区域/窗口选择、帧率、暂停、光标与按键显示、音频输入及输出格式。
- 录制结果裁切、片段处理、帧导出；错误恢复、磁盘空间与文件生命周期。
- 截图后动作链、命令行调用、外部工具集成。
- 若“完整对齐”包含 ShareX 分享生态：上传目标、凭据管理、失败重试、链接回传与历史；上传必须是明确启用的动作。
- 跨平台、云同步、账号/会员等单独评估，不把 Windows 截图编辑需求隐式变成这些产品工程。

验收：录屏/自动化独立能力契约与 E2E；主应用仍由 C# 承担系统能力，Web 只做展示与局部编辑，Runtime 保持 OCR/PDF/模型职责。

## 交付与边界

建议按 P0 → P1 → P2/P3 → P4 → P5 → P6 推进，每阶段独立可用、可验收。不承诺一次变更完成全部竞品功能，也不把按钮占位作为已实现。下列 Task 已按可独立验收行为拆分；远期项在进入实施时重核接口和验收，避免提前设计无消费者框架。

本清单覆盖截图产品主要用户流程。竞品商业版本、平台差异及后续新增功能需在对应阶段再次核实；“待补齐”是本项目目标，不代表两款竞品都拥有该表中的每一项。
